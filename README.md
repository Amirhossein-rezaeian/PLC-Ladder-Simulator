# 🇬🇧 PLC Ladder Simulator

**PLC Ladder Simulator** is a new interactive project for **PLC programming, Ladder Logic simulation, learning, and practice**.

It is designed for students, engineers, industrial automation enthusiasts, and anyone interested in learning PLC programming through an interactive simulation environment.
